GENERAL INSTRUCTIONS For each question, students are required to: 1. Develop an application containing five Java classes, including the Main class. 2. Ensure that each of the four domain classes contains exactly five attributes. 3. Apply encapsulation, constructors, getters and setters. 4. Establish appropriate relationships between the classes. 5. Override the toString() method in all four domain classes. 6. Allow the user to enter information during program execution. 7. Register objects in the specified order. 8. Implement appropriate validation for all attributes. 9. Handle invalid input and exceptions without unexpected program termination. 10. Allow the user to correct invalid information. 11. Display all registered objects only after successful completion of all registrations. 12. Independently determine the appropriate implementation approach.
